### Hi there 👋

I am Nikhil Raj, a Senior Frontend Engineer with 9+ years of experience building high-performance, data-intensive web applications at scale. Specialised in frontend architecture, complex UI systems, and performance optimisation across Angular, React, and Ember.js ecosystems.

I've led development of micro-frontend platforms, real-time analytics systems, and hybrid mobile applications serving hundreds of thousands of users. Active user of AI-assisted development tools including Claude Code and GitHub Copilot.

#### 🎯 What I Do

- Architect and build scalable frontend systems — micro-frontends, SPAs, design systems, and component libraries
- Optimise rendering performance, state management, and delivery pipelines

- Work across Angular (Signals, RxJS), React, Ember.js, TypeScript, and modern tooling
